# 实验版本定义

为了验证本系统引入护栏机制（Guardrail）与状态机（FSM）的有效性，我们设计了三个不同的系统版本进行消融实验：

## 1. Baseline
**定义**：基线版本，即直接使用单一的大语言模型进行对话，不经过意图识别、护栏检测和状态机管理。
**实现方式**：
- 用户输入直接传递给大语言模型（LLM）。
- 大语言模型直接生成回复并返回给用户。
- 模拟常规的不具备教育领域特定策略和安全管控的通用对话机器人。

## 2. FSM (有限状态机)
**定义**：在 Baseline 的基础上，引入了基于教育认知理论设计的有限状态机流转机制，但去除了护栏检测（Guardrail）。
**实现方式**：
- 使用 `Router` 进行意图识别。
- 使用 `Classifier` 提取迷思概念并进行教育状态分类。
- 使用 `Generator` 依据当前认知状态生成针对性的苏格拉底式提问或引导。
- **跳过护栏检查（Guardrail）**：所有用户的输入都默认判定为安全（Safe），即使存在恶意注入或不当内容，系统也不会触发拒绝策略。

## 3. FSM+Guardrail (完整版)
**定义**：系统的完整形态，既包含教育领域的状态机引导机制，也包含严密的护栏安全策略。
**实现方式**：
- 完整执行当前的设计流程：
  1. `Guardrail` 模块优先对用户输入进行安全检查（包括恶意注入检测和越界问题检测）。
  2. 若输入不安全，系统触发拒答策略并直接回复。
  3. 若输入安全，继续通过 `Router` 意图识别和 `Classifier` 状态流转。
  4. 最后由 `Generator` 根据状态生成教育性回复。
- 能够在保障对话安全性的前提下，实现逐步引导学生修正迷思概念的目标。
